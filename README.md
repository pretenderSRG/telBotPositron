# Telegram Assistant Bot "ПОЗИТРОН"

Telegram-бот українською мовою з інструментами на базі OpenAI API. Проєкт працює через Telegram long polling і підтримує асинхронні обробники на `aiogram`.

## Можливості

- Відповіді на запитання через OpenAI.
- Діалог із відомою людиною або персонажем; контекст діалогу зберігається у стані поточного процесу.
- Вікторина з вибором теми, оцінюванням відповідей і підрахунком результату.
- Випадкові факти.
- Персональні рекомендації з можливістю відхилити результат.
- Генерація плану тренувань за типом програми, кількістю днів та доступним обладнанням.

## Технології

- Python 3.10 або новіший.
- `aiogram` 3 для Telegram Bot API.
- OpenAI Python SDK для мовних запитів.
- `python-dotenv` для завантаження параметрів із `.env`.

Залежності зафіксовані у [`requirements.txt`](requirements.txt).

## Налаштування та запуск

Потрібні токени Telegram-бота від BotFather та API-ключ OpenAI з доступом до вибраної моделі.

### Windows PowerShell

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

### macOS або Linux

```bash
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
cp .env.example .env
```

Скопіюйте `.env.example`: замініть значення `BOT_API_KEY` та `OPEN_API_KEY` на власні секрети. Потім запустіть бота з кореня проєкту. При потребі змініть значення необхідних параметрів.

```powershell
.\.venv\Scripts\python.exe main.py
```

```bash
.venv/bin/python main.py
```

Успішний запуск завершується повідомленням `Запуск бота...`. Процес потрібно залишити активним, щоб бот відповідав на повідомлення. Для одного токена бота запускайте лише один екземпляр polling-процесу.

## Конфігурація

Значення читаються з `.env`. Обов'язкові параметри перевіряються під час запуску.

| Змінна | Обов'язкова | Значення за замовчуванням | Призначення |
| --- | --- | --- | --- |
| `BOT_API_KEY` | Так | Немає | Токен Telegram-бота. |
| `OPEN_API_KEY` | Так | Немає | API-ключ OpenAI. Назва змінної саме `OPEN_API_KEY`. |
| `OPENAI_MODEL` | Ні | `gpt-4o-mini` | Модель OpenAI для текстових запитів. Вкажіть модель, доступну вашому акаунту. |
| `OPENAI_REASONING` | Ні | `none` | Рівень reasoning, який передається до Chat Completions API. |
| `OPENAI_MAX_TOKENS` | Ні | `600` | Ліміт токенів відповіді. |
| `OPENAI_TIMEOUT` | Ні | `30` | Таймаут запиту до OpenAI у секундах. |
| `MAX_GPT_HISTORY` | Ні | `10` | Максимальна кількість повідомлень історії діалогу з персонажем. |
| `LOG_PATH` | Так | Немає | Шлях до файлу журналу, наприклад `logs.log`. Відносний шлях задається від поточної робочої директорії. |
| `USERS_FILE` | Ні | `users.json` | Шлях до JSON-файлу з Telegram ID та профільними даними користувачів. |

Не додавайте справжні токени або API-ключі до Git. Файл `.env` виключений із Git через `.gitignore`; зберігайте його лише локально або використовуйте захищене сховище секретів у середовищі розгортання.

## Команди бота

| Команда | Дія |
| --- | --- |
| `/start` | Показати головне меню. |
| `/help` | Показати довідку. |
| `/random` | Отримати випадковий факт. |
| `/gpt` | Розпочати діалог із GPT. |
| `/talk` | Обрати людину або персонажа для діалогу. |
| `/quiz` | Розпочати тематичну вікторину. |
| `/recommend` | Отримати рекомендацію. |
| `/gym` | Скласти план тренувань. |

Ті самі сценарії доступні через кнопки головного меню. Завершення сценарію виконується кнопкою «Закінчити» або командою `/start`.

## Структура проєкту

```text
.
├── catalog.py              # теми, категорії та варіанти вибору
├── chat_gpt.py             # інтеграція з OpenAI Chat Completions API
├── config.py               # читання та перевірка конфігурації
├── filters.py              # фільтри вхідних повідомлень
├── main.py                 # запуск бота, polling та підключення роутерів
├── handlers/                # обробники команд і сценаріїв
├── keyboards/               # Telegram inline та reply-клавіатури
├── middlewares/             # проміжна обробка, зокрема throttling
├── resources/
│   ├── images/              # статичні зображення сценаріїв
│   ├── messages/            # тексти повідомлень
│   └── prompts/              # системні промпти для OpenAI
├── utils/                   # завантаження ресурсів та налаштування логів
├── .env.example             # шаблон локальної конфігурації
└── requirements.txt         # зафіксовані залежності Python
```

## Дані та приватність

Бот передає текст користувацьких запитів до OpenAI для формування відповідей. 

### -- ВАЖЛИВО!!! -- 
Не надсилайте через бота секрети або дані, які не можна передавати зовнішньому API. При `/start` бот зберігає Telegram ID, username, ім'я та прізвище у файлі, заданому `USERS_FILE`.

FSM-стани зберігаються в оперативній пам'яті процесу: вони не переживають перезапуск бота. Контекст діалогу з персонажем обмежений поточною FSM-сесією.

## Перевірка змін

У репозиторії немає налаштованого набору автоматизованих тестів. Для перевірки синтаксису Python-модулів перед зміною або pull request виконайте з кореня проєкту:

```powershell
.\.venv\Scripts\python.exe -m compileall -q catalog.py chat_gpt.py config.py filters.py main.py handlers keyboards middlewares utils
```
